# Water Afterlife

- Keep `slug` equal to `DW_260928_Water Afterlife`.
- Upload images into this folder, then set `hero.file` and `images[].file` to their relative filenames.

- Set location coordinates to `[longitude, latitude]`, or leave them `null` until known.
- Add narrative paragraphs as strings in `description`.
- Once the content and images are ready, add `DW_260928_Water Afterlife` to `../index.json` to include it in the website's project listings.
