# Trail for Healing the Burn

Web images are optimized JPEGs, up to 2400 pixels on the long edge, without cropping. Original uploads remain in the local source folder.

Edit `info.json` to update the project. `webLink` contains an optional `label` and HTTPS `url`, displayed in the project sidebar. The narrative is a concise adaptation of the linked WLA article.

Map coordinates mark the approximate Greenville area, not an exact project boundary.
